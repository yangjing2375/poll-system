## 六、遗留问题与风险

1. **BUG-11（高）编辑投票导致票数清零**
   管理员在管理端保存投票时会先删除该投票的全部选项再重建，`poll_votes` 因外键级联被一并删除，历史票数归零。当前规避方式为：编辑前先导出结果数据。修复方向是按 `option_id` 做增量更新，删除选项前校验是否已有投票。

2. **BUG-12（中）我的投票记录中创建者显示错误**
   `polls.creator_id` 的外键指向 `users`，而管理员创建的投票写入的是 `admin_id`；当管理员 id 与某个用户 id 相同时，`get_user_votes.php` 的 `JOIN users` 会把创建者错误映射成该普通用户。修复方向是增加 `creator_type` 字段并改为 `LEFT JOIN users + LEFT JOIN admins`。

3. **建议项（非缺陷）**：生产环境应关闭 `display_errors`，统一由 `Logger` 输出异常；`polls.creator_id` 的外键设计需要与 BUG-12 一并调整。

## 七、结论

本轮共执行 84 条用例，通过 81 条，通过率 96.4%；高优先级的功能与安全问题（投票状态校验、多选数量校验、事务写入、异常信息回显、上传类型校验、分页越界）已全部修复并回归通过，接口自动化与 CI 保持全绿。剩余 2 条缺陷集中在「编辑投票的数据保留」与「创建者归属」两个设计问题上，已登记 Issue 并给出修复方案，不阻塞现有功能使用。
